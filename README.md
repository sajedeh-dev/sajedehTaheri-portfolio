# Sajedeh Taheri — Portfolio

Personal frontend portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run start
npm run lint
```

The app runs at [http://localhost:3000](http://localhost:3000).

## Content

All portfolio copy lives in `src/data/portfolio.ts`.

- Profile, skills, and contact links are filled in.
- `projects` and `experience` are empty arrays until you add real case studies and roles.
- Education and certifications live on `resumeExtras` and stay hidden while empty.

## Environment

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL` for canonical URLs and the sitemap.

## Assets

Put future images in:

- `public/images/profile/`
- `public/images/projects/`
- `public/og-image.png` for social sharing
